# Fonts

Self-hosted so the build never has to download fonts from Google
(a Google Fonts fetch at build time broke the Render build).

| File | Font | Used for | License |
|---|---|---|---|
| `LeagueScript-Regular-latin.woff2` | [League Script](https://fonts.google.com/specimen/League+Script) | wordmark, big titles | SIL Open Font License 1.1 |
| `Lato-*-latin.woff2` | [Lato](https://fonts.google.com/specimen/Lato) 100–900 + italics | headings | SIL Open Font License 1.1 |
| `Literata-Variable{,-Italic}-latin.woff2` | [Literata](https://fonts.google.com/specimen/Literata) (variable, 200–900, opsz 7–72) | body text | SIL Open Font License 1.1 |
| `DMMono-{Light,Regular,Medium}-latin.woff2` | [DM Mono](https://fonts.google.com/specimen/DM+Mono) 300/400/500 | search bar, buttons, labels | SIL Open Font License 1.1 |

All are Latin subsets downloaded unmodified from Google Fonts (fonts.gstatic.com).
The OFL allows bundling and redistributing them with software.
